Use this tool when the implementation plan is decision-complete and ready to be saved.

Pass the complete Markdown plan in the plan parameter. The tool saves it to the session's plan file, then asks whether to switch to Build and start implementing.

Call this tool:
- After you have presented the same complete plan in the chat
- After you have clarified any questions with the user
- When you are confident the plan is ready for implementation

Do NOT call this tool:
- Before you have finalized and presented the plan
- If you still have unanswered questions about the implementation
- If the user has indicated they want to continue planning

Do not create or edit the plan file directly. This tool is the only write operation available in Plan mode.
